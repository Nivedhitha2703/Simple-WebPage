# Simple HTML Page

A basic HTML webpage created to demonstrate fundamental HTML elements and formatting tags. This project is ideal for beginners learning web development and understanding the structure of a webpage.

## Features

* Page Heading
* Paragraph Text
* Underlined Text
* Italicized Text
* Bold Text
* Unordered List
* Horizontal Line
* Colored Text Using Font Tags
* Simple Page Layout

## Technologies Used

* HTML5

## Concepts Demonstrated

* HTML Document Structure
* Headings (`<h1>`, `<h2>`)
* Paragraphs (`<p>`)
* Text Formatting Tags

  * Bold (`<b>`)
  * Italic (`<em>`)
  * Underline (`<u>`)
* Lists (`<ul>`, `<li>`)
* Horizontal Rule (`<hr>`)
* Font Coloring
* Background Color Styling

## Purpose

This project was developed to practice basic HTML tags and understand how different formatting elements are used to structure and present content on a webpage.

## Learning Outcomes

* Understanding HTML document structure
* Using text formatting tags
* Creating lists
* Adding colors and styling using HTML attributes
* Building simple webpages

## Future Improvements

* Add CSS for modern styling
* Improve page layout and typography
* Make the webpage responsive
* Replace deprecated tags with CSS styling
